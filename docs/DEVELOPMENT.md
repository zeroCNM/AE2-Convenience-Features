# AE2 Convenience Features 0.11

独立的 Minecraft 1.7.10 / GTNH 2.9.0 模组，客户端和服务端均安装。

## 功能

- 玩家 AE 订单实际制作完成后，在同一网络终端顶部显示临时物品行：最新完成的排最前，同物品按 meta/NBT 去重，按终端列数补齐整行，超出自动续行。未打开终端时等待下一次打开同网络终端；关闭后清除，持续打开则从首批显示起 60 秒整栏清除。再次完成的订单可开始新一批临时行。取物仍走原生 AE 槽位和服务端校验。

- 携带有效的 AE2 无线终端，在 NEI 右侧、历史栏、左侧书签以及配方页按 Shift+右键取 1，Shift+左键取一组。无可提取库存但有样板时进入 AE2 原生数量/确认下单流程。
- 在上述 NEI 区域按住空格单击左键，将现有库存填入背包/快捷栏的空位及同物品未满堆叠；一次点击一次请求，无需 Shift，也不需要持续按住鼠标。只在开始时零库存且有样板才下单，部分库存不补单。
- 零库存不显示数字；有样板且具备合成权限时，物品左上角显示白色 `+`。右侧和历史栏物品的库存数量为右下白字；配方页内物品与左侧书签为左下绿字，均贴格子底部。配方页左侧机器列表不显示库存或加号。刷新直接替换快照，不周期隐藏数字；连续 10 秒收不到有效数据后停止显示旧数字。
- NEI 中键：右侧、历史、左侧书签/标签和配方页均支持，无需 Shift。有样板时直接进入原生下单页，即使已有库存也可以下单，不提取库存。
- 世界中键：优先选中背包已有的同物品（精确 meta/NBT），否则从 AE 提取至快捷栏并选中；没有库存但有样板则下单。不会覆盖或删除原手持物品，背包满时拒绝提取。
- F 键将悬停物品名写入 AE2 终端、接口终端、诊断终端的搜索框；兼容 GTNH 自带 AE2FC 的等级终端及无线等级终端。文本框已有焦点时不抢键。
- 主背包无线终端优先，饰品终端通过可选隔离桥支持。服务器检查注册 handler、绑定、安全站、电量、范围、EXTRACT，合成另查 CRAFT。

旧模组的样板上传、样板总成/多方块配方池适配不迁入。本模组不依赖 AE2-Auto-Pattern-Upload、NotEnoughEnergistics、TenkeiTech 或其他额外扩展。

## 安装

1. 客户端与服务端从 mods 移除旧 AE2-Auto-Pattern-Upload，备份原 jar。
2. 双端加入 `AE2 Convenience Features 0.11.jar`，删除旧版功能包。不要安装开发包 `dev.jar` 或源码包 `sources.jar`。
3. 原 GTNH 2.9.0 自带 AE2、GTNH NEI、CodeChickenLib、UniMixins 已满足必需运行条件。Baubles 为可选，AE2FC 搜索兼容没有硬类型依赖。
4. 新配置生成在 `config/ae2conveniencefeatures.cfg`。`neiActions`、`neiMiddleCraft`、`inventoryOverlay`、`worldPickBlock`、`completedCraftRows` 可单独关闭；`searchKeyCode=33` 表示 F，设 0 关闭。

不需要安装任何额外第三方模组。不要同时保留新旧两个功能模组，否则旧模组仍会注册自己的网络与按键处理。

## 输入共存

NEI 中键在当前 GTNH NEI 的 `GuiContainerManager.handleMouseHotkey` 入口接管，早于配方页和各模组的点击通知/下单热键。旧版 NEI 则由管理器和配方页的 HEAD 注入接管。只消费携带终端、悬停 NEI 物品的中键及其释放/拖拽；已缓存确认无样板、无终端、普通背包槽位或关闭功能时放行。冷缓存由服务端确认一次，不重放同次输入给其他模组，也不修改其他模组配置。服务端另有频率限制，并重新验证样板和权限。


在世界、生存模式、目标是可拾取形式方块、携带已注册且绑定的无线终端时，最高优先级 Forge MouseEvent 只消费本次中键按下，防止它继续触发 AE2 自带 PacketPickBlock 或已核实的同类 middleClickMouse Mixin。已被其他处理器取消的事件会立即放行。

没有无线终端、GUI 打开、创造模式、目标非方块或关闭本功能时，不改变原版输入。服务器明确拒绝且没有提取/打开下单界面时，仅回退 Forge 原版背包选中，不重放给网络取物模组。ACK 超时不重发、不回放，避免重复取物/重复下单。

已核实 AE2 977/1095、GTNHLib 0.11.9/0.11.54、Pro 中 sciencenotleisure 与 GregTech 的事件路径。未知模组若绕过 Forge 输入取消而独立轮询，仍需在该组合中实测；不承诺所有未知第三方实现均已验证。

## 构建与校验

JDK 17 运行 Gradle，Java 8 字节码输出：

```sh
bash build.sh spotlessApply build
python3 scripts/audit-artifact.py "build/libs/AE2 Convenience Features 0.11.jar"
```

`build` 自动运行实际 Minecraft 物品/NBT、Forge/Netty 编解码、缓存及手持物品守恒回归。具体运行结果、接口核实和 14 项自检随交付报告提供。构建通过不能代替 GTNH 客户端交互实测。

每次发布功能更新都递增一次版本号，统一维护根目录 `VERSION`；构建和产物审计均读取该文件。同一次更新重复构建不增加版本。本次为 0.11，下一次为 0.12，历史交付保留。

## 完成物品临时栏

此功能覆盖 AE2 原生存储终端及其兼容子类，不要求身上携带无线终端。它在实际完成回调触发，取消或提交失败不计入。合并订单按成功提交时记录的玩家分发；原生 CPU 从存档恢复的订单可使用 AE 保存的来源玩家兜底。只显示下单目标物品，不把配方中间产物和副产物加入栏位。

临时栏使用终端原生库存引用，数量随原生同步更新；显示排序独立于普通搜索，普通列表中同物品被移到临时行。已有原生固定栏仍保留，在可见的临时行下方显示。翻页滚动后，两部分的点击位置跟随实际显示。临时行沿用终端的滚动区域，记录较多时可滚动查看。最多保留最近 256 种完成物品，满后淘汰最旧的。

在 AE 数量、确认、CPU 状态子页面之间切换视为本次终端访问的延续；主动关闭、切到其他普通界面或不同 AE 网络会清除已显示记录。待显示的完成记录按网络隔离，显示后从服务器队列消费，不会关闭重开后再次出现。服务器重启会清除尚未显示的临时记录；已持久化的原生订单仍由 AE 继续制作。

## 0.9 保守优化

完成栏本地变化仅在已由 AE 筛选和排序的 view 上调整显示，不再主动调用原生 updateView；无完成物品的首次绑定不触发整表刷新。原生库存、搜索、排序、Shift 暂停更新仍按 AE 自身流程运行，进入原生更新前恢复完整原视图。快照容器和最近完成顺序可复用；无临时行时跳过坐标扫描，位置未变时不写坐标，但保留逐帧观察以兼容其他模组改动位置。

NEI 相同 ItemStack 的标识使用有上限的弱引用缓存，每次命中仍比较物品、meta 和完整 NBT；嵌套 NBT 原地修改也立即失效。世界中没有 NEI 界面和待处理取物请求时，不再逐 tick 扫描无线终端。服务端无新增完成记录、终端和网络未变时，不分配空完成通知包。没有调整安全校验、输入优先级、同步频率、网络包编号或 NEI 500 ms 有效期。

用户复测后卡顿未稳定复现，本轮没有证明其根因。171 项回归与静态字节码审计用于检查行为和重复工作；未采集客户端帧耗时，不把这些结果换算成 FPS 提升。

## 0.10 配方页库存数字

NEI 配方查看页面内物品的库存数字改为左下角绿色，与左侧书签使用相同样式（0x7EFFB3），仍贴格子底部。新旧 NEI 配方控件共用这一绘制入口；白色可合成加号、零库存隐藏和配方页机器列表排除规则保留。

## 0.11 空格点击填满背包

空格+左键在已有 NEI 输入接管点处理，并跟踪被接管按键的松开和拖动，避免同一次点击继续触发默认配方/作弊取物。无终端、非 NEI 物品和未满足快捷键时放行。空格+Shift+左键优先填满背包；原 Shift 单独操作保留。

复用原无线操作包，新增动作 3，动作 0/1/2 和网络包编号不变。客户端不提供数量；服务端继续验证维度、配置、100 ms 限流、绑定、电量、范围及权限，再计算普通 36 格（含快捷栏）的实际容量。不使用盔甲、额外槽位或鼠标光标，也不替换已有物品，精确比较 meta/完整 NBT。

库存为零走原有样板及 CRAFT 权限检查。有库存时按容量进行一次 AE 原生耗电提取，提取结果拆成合法堆叠，先合并再填空位。库存或电量不足只交付实际提取数量，不进入下单分支；背包满时不提取。提取后重新核对槽位，放不下的余量退回 AE，退回也被拒绝时仅掉落实有余量并拆成合法堆叠。容量和放置各最多扫描 36 格，不新增 tick/渲染扫描或网络请求频率。
